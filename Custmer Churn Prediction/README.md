#  Customer Churn Prediction App

A Machine Learning web application built using Streamlit that predicts whether a customer will churn or not based on various input features.

##  Project Description

Customer churn is a major problem in telecom and service-based companies. This project helps in predicting whether a customer is likely to leave the service or not using a Logistic Regression model.

The application takes user inputs like tenure, contract type, charges, and other customer details to make predictions.
